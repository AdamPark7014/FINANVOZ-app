# Lote final de capturas

- `ios-6.9/` — iPhone 6.9" (1320 × 2868), enmarcadas. Las sube `py -3 scripts/tienda/asc-ficha.py` al set
  `APP_IPHONE_67` de la versión 1.0.0 (borra las que ya no estén, sube las nuevas, respeta el orden del nombre).
- `android-telefono/` — teléfono Android (1080 × 1920), enmarcadas. Se suben por navegador a Play Console
  (`../play/ficha.md`).

Cómo se generan (flujos `ios-capturas.yml` y `android-capturas.yml`, `enmarcar.py`, plan y titulares):
[`../capturas.md`](../capturas.md). Un lote es **provisional** mientras la interfaz siga cambiando; se regenera y
se vuelve a commitear entero cuando el coordinador lo pida.
